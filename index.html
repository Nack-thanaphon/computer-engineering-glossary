อัตราการเปลี่ยนแปลง — ถามว่า "y เปลี่ยนเร็วแค่ไหนเมื่อ x เปลี่ยน"

"ถ้าเป็น dynamic คุณจะเห็นตัว diff หลุดออกมาแน่ ๆ"

เทคนิคแก้ ODE โดยย้าย y ไปซ้าย, t ไปขวา แล้วอินทิเกรต

"dy/(y−5000) = −0.01 dt"
\[\frac{dy}{dt}=-ky\ \Rightarrow\ \frac{dy}{y}=-k\,dt\ \Rightarrow\ y=Ce^{-kt}\]
Integration (\(\int\)) การอินทิเกรต / ปริพันธ์ ต้องเรียน

ย้อนกลับของอนุพันธ์ — รวมอัตราการเปลี่ยนแปลงเป็นค่าทั้งหมด

"อินทิเกรตทั้งสองข้าง ได้ ln(y−5000) = −0.01t + c"
\[\int_0^2 x^2\,dx=\frac83\]

ฟังก์ชันที่เกิดจากการอินทิเกรต 1/x

"∫ dy/(y−5000) = ln(y−5000)"
\[\ln x=\log_e x,\quad \int\frac{dx}{x}=\ln|x|+C\]

ฟังก์ชันที่ยก e (≈2.718) ยกกำลัง

"ยก e ทั้งสองข้างเพื่อกำจัด ln"
\[y(t)=5000-4900e^{-0.01t}\]

"ที่ t=0, y=100 → 100 = 5000 + c → c = −4900"

ค่าที่ระบุที่ขอบเขตของระบบ (เหมือน initial แต่ที่ขอบ)

"สมการเริ่มจาก equilibrium กับ conservation law"
\[\frac{dy}{dt}=0,\quad y^*=5000\]

"dT/dt = อัตราการเปลี่ยนแปลงของอุณหภูมิ"

Depth-First Search (DFS)สำรวจลึกก่อนย้อนกลับสำคัญ

\[\text{stack: LIFO},\quad T=O(V+E)\]
ลองตามตัวอย่าง

  2. จาก B → ไป D; D ไม่มีเพื่อนใหม่
  3. ย้อนกลับ B แล้ว A → ไป C
  4. จาก C → ไป E; ลำดับ A,B,D,C,E

ดู pseudocode — วิธีทำแบบย่อ

        if v not seen: dfs(v)

Dijkstra’s Algorithmหาทางรวมค่าเดินทางน้อยสุดสำคัญ

เลือกโหนดที่มีระยะสะสมต่ำสุด แล้วปรับระยะเพื่อนบ้าน

เข้า: A–B:1, A–C:4, B–C:2, B–D:5, C–D:1 • ออก: A→B→C→D ระยะ 4

\[d(v)\leftarrow\min\{d(v),d(u)+w(u,v)\}\]
ลองตามตัวอย่าง
  1. ตั้ง d(A)=0, ที่เหลือ = ∞; จาก A ได้ B=1, C=4
  2. เลือก B ระยะ 1 → ปรับ C=3, D=6
  3. เลือก C ระยะ 3 → ปรับ D=4
  4. เลือก D ระยะ 4 → ย้อน predecessor ได้ A→B→C→D
1 / 4
ดู pseudocode — วิธีทำแบบย่อ
dist[start] ← 0; others ← infinity
priority_queue ← [(0,start)]
while queue not empty:
    d,u ← pop smallest distance
    if d ≠ dist[u]: continue
    for edge u→v with weight w:
        if d+w < dist[v]:
            dist[v] ← d+w; parent[v] ← u
            push(dist[v],v)
return distances and parents

จำง่าย / ระวัง: กราฟตัวอย่างเป็นขอบสองทาง; ต้องระบุทิศทางและหน่วยน้ำหนักในงานจริง
